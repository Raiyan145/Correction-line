# Line Fixer AI
Corrects your line in many styles (Normal, Casual, Gen Z, Friendly...) — Bangla, Banglish, English.

## Deploy on GitHub (free)
1. Create a new repo, upload all files from this zip.
2. Repo > Settings > Pages > Source: "Deploy from branch", branch `main`, folder `/ (root)`.
3. Open the Pages link, paste your Gemini API key once (get it at https://aistudio.google.com/apikey).

The key is saved only in your own browser (localStorage). Never commit it into the code.
